About TaskFlow

TaskFlow is a simple To-Do List app to help users organize daily tasks and improve productivity.

Features

  • Add tasks
  • Edit tasks
  • Mark completed
  • Delete tasks
  • Search tasks
  • Clear all tasks
  • Task statistics
  • Local storage support

Built With

HTML5, CSS3, Vanilla JavaScript
